# 中文科学漫画原画观察：可借的推进方式与必须纠正的图解

本次实际查看两项中文公开作品的原画：一项完整六格，一项高校漫画的开头五幅。它们用于分析构图、语言和科学表达，**不代表已找出最受广东高三喜欢的风格**，也不作为播放量、提分或偏好证据。网页介绍不能代替原画，官方平台承载也不能代替逐格核对。

## 1. 科普中国公开六格：水果电池任务

来源：[科普中国作品页](https://www.kepuchina.cn/article/articleinfo?ar_id=714549&business_type=100&classify=0)。页面显示上传于2026-06-25，展示中国科普作家协会账号，另注明内容贡献者；不能据此推定某专家已审过全部画面。

观察范围：[页面内公开原图](https://pqnoss.kepuchina.cn/declaration/2026/03/17/23/1773673039728.jpg)，4096×4096，按从左到右、从上到下查看全部六格。网页工具未能打开页面和图片，后台普通公开请求成功取得HTML及其图像；已用图像查看工具真正看图。临时观察副本位于系统临时目录，未放入项目或公开仓库。

以下为观察概述，无对白长段摘录：

| 位置 | 实际看到的推进 | 有效之处与不足 |
|---|---|---|
| 第1—2格 | 断电任务引出水果、两种金属和防护道具；人物表情与材料台切换 | 先有目的，再认识材料；角色主要发指令，尚未提出机制问题 |
| 第3—4格 | 插入两极并出现火花式符号，随后展示多个水果与电表 | 从操作走向测量；标注0.8V→2.4V，表盘却仍为0.8V，接线也不够可核对 |
| 第5—6格 | 小灯与地图构成结果画面，最后用奖章结束 | 首尾闭合、视觉尺度变化；弱电源却配火花和常见灯泡外形，容易让效果先于机制 |

**判断与科学核对：** 该作品的任务节奏可以借鉴，科学图解应重画。它未清楚展示锌的氧化、铜侧的还原及外电路与溶液中不同的电荷运输机制。不能让学生误以为水果本身储藏着待释放的电，或电子自由穿过电解质。美国化学会的公开教学活动把电极、电解质及两条运输途径分别说明；科罗拉多大学演示手册给出酸性简化模型中的两条半反应及正确串联方式。[ACS活动原文](https://www.acs.org/education/celebrating-chemistry-editions/2024-ccew/build-a-battery-workshop-from-nature-to-battery.html)、[科罗拉多大学演示手册](https://www.colorado.edu/lab/lecture-demo-manual/electrochemistry/x824-lemon-battery)

串联图应能从一端沿导线追踪至另一端，每个水果必须区分铜、锌两个端点。把三节各0.8V相加作为理想化算例可以，但数字应与接法、测量位置、仪表同时一致。现实输出受材料、接触、内阻和负载影响，不把固定电压或一定点亮某LED画成普遍保证。澳大利亚国立大学的活动页展示了跨水果正负极串接、端点测压及LED极性，可用作装置核对参考。[ANU公开活动](https://science.anu.edu.au/engagement/science-lab-experiments-home-school/how-make-lemon-battery)

### 面向高三的原创改写办法

这不是复刻原作人物、画风或台词，而是保留“任务—试错—原理—验证”的功能结构。建议六幕，每幕推进新的因果信息：

1. **制造可解释的矛盾。** 人物测到电压，但接上灯后不亮，提出“有电压为什么还不亮”的问题，连接化学原电池和物理闭合电路。
2. **放大一个电极。** 把锌原子、进入溶液的离子与留在金属中的电子分开，列出Zn→Zn²⁺+2e⁻；这不是让一个拟人角色从锌片跳进水果。
3. **追踪两种载流路径。** 外部电子沿导线经负载到铜侧，溶液内部用离子运动表征；酸性简化模型中用2H⁺+2e⁻→H₂解释铜侧反应，并注明模型条件。
4. **让学生预测再串联。** 给出三个规范单元图，请学生选正确接法；用真实端点和电压表读数验证，而不是只画三个水果相连。
5. **带负载看变化。** 同一接线下比较开路与带负载，明确示意数据与实测数据；不编造实验录像或仪表实测。
6. **迁移到陌生电源。** 给出不同材料与介质，让学生识别氧化/还原处、电子方向和离子作用，再回顾原理卡。

以上分镜为项目原创教学建议，尚未由学科教师审核或制作成片。视觉夸张用于情绪和任务紧迫感；反应方向、线路、量纲及仪表数据使用规范图解，不能跟随夸张变形。

## 2. 国科大公开漫画：教师幽默与理想化模型

来源：[中国科学院大学物理科学学院作品页](https://physics.ucas.ac.cn/index.php/zh-CN/wyss/5520-2023-02-22-03-24-01)。页面署钟赟、林天予，说明原载《国科大》2018年第四期，学院网页于2023年转载。它首先是课堂人物观察漫画，**不能把它包装成完整高中热学课程**。

- [第五幅，真空中形状简化的例子](https://physics.ucas.ac.cn/images/2023/20230222112210.jpg)

已实际看这五幅；未看页面后五幅，不宣称读完全文。后台普通请求取得公开图片并以图像查看工具观察，原件未加入项目。

**画面观察：** 黑白手绘、大量留白和连续人物形象构成课堂感。开场先降低紧张，继而切到群聊，再把复杂对象简化成几何体；第五幅用并排容器制造对照，笑点来自模型与常识之间的反差。它并非靠满屏彩色素材或不断加梗推进。

**教学取舍：** 可借有辨识度的引导者、学生能表达疑问的语气和由具体对象进入模型的转换。不能把球形近似当作免解释的万能借口：高三内容必须说明研究什么量、忽略什么、为何可忽略，最后验证结论对真实对象是否仍适用。上述片段没有完成这一整条论证，因此仅可借导入结构，不能据此声称已证明某个物理结论或偏好效果。

## 两项作品给本平台的具体设计约束

| 观察问题 | 平台制作要求 | 可验收证据 |
|---|---|---|
| 任务或笑点先抓注意，机制可能被挤掉 | 每个关键知识点让角色至少经历预测、观察和解释，少用只宣布结论的口号 | 逐幕脚本能标出提出的问题、可见证据与被纠正的误解 |
| 人物形象连续不等于画面单调 | 保持原创角色一致，镜头在情境、微观机制、规范图与应用之间有目的切换 | 相邻镜头的信息确有增加，不以缩放、换色、抖动凑动画 |
| 有趣比喻会掩盖条件 | 每个比喻标明“对应哪部分”及“在哪停止成立” | 条件卡、反例和迁移题均能对上原理 |
| 一处数字或接线错误足以破坏信任 | 数字、公式、线路和图例独立于美术气氛复核 | 科学审稿记录加关键帧放大检查，而非只看缩略图漂亮 |
| 静态优秀布局不自动等于动态优秀 | 动画让因果依次发生，读数随状态更新；完成后停住供操作 | 可暂停、逐步观察；没有长时间无信息循环或错误仪表 |

作品页面并未提供可复用美术的开放许可。本次只保留来源链接和原创分析，不复制人物、整篇图像或连续对白；后续若需直接改编，须先核权利。没有广东高三用户样本，下一步应以真实学生解释题、变式题和延迟回忆检验，而不把官方账号、画风选择或热度当学习效果。
