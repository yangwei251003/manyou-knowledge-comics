# 0.2四视角体验走读

日期：2026-11-06。由同一AI按不同任务视角检查实际网站，不是四名真人或独立专家评价。没有教师教审、学生访谈和学习效果样本。

## 统一标准

所有视角使用相同五项，每项0–5，换算为百分制：内容覆盖与查找25%、科学条件与表达25%、理解与迁移25%、阅读交互15%、状态可信10%。没有观察证据的项目不按满分处理。科学硬错、缺资源与虚假完成状态为先修问题；完整视频质量另按声音与视频标准，不与网站分数混算。

## 真实走读与发现

| 视角 | 实际任务与证据 | 本轮判断 |
|---|---|---|
| 高考生视角 | 从首页选科、跨科搜索减数分裂、打开章节、遮住解答、记思路、刷新继续；手机逐页检查 | 比五样章结构明显更可查；大部分章节仍以文字为主，中档综合练习不足 |
| 老师视角 | 对照教材节标题；检查公式条件、DNA计数、能量与电流方向、平衡Q/K和太阳高度；检查拒用图稿及返修 | 章节映射有证据，科学高风险点有检查；仍需真实教师逐条教审，不给出课程有效性结论 |
| 开发者视角 | 桌面与375px手机各115章路由；搜索、笔记刷新、收藏、导出、模型与弹窗、无控制台异常或缺资源 | 静态网站主要流程可运行；账户同步、跨设备恢复与大型素材管理尚未实现且已明确说明 |
| 前端审美视角 | 查看首页、课程书架、章内长文、公式、漫画、手机模型 | 纸张、墨绿、学科色与留白一致；较小的模型标签可放大；漫画在课程中的覆盖率仍低 |

已根据这些发现返修：不再首页只展示五个主题；完整目录与跨科搜索进入主路径；补公式条件和题型卡；全章回顾与24条关系路线覆盖所有章节；模型增加放大；科学图错稿拒用，三页局部返修。未以角色切换修改全局人设或冒充真人身份。

先做逐节教审和错因导向题型，再推进有知识映射的漫画与独立短视频；开展真实学生任务测试后，按证据调整阅读密度、路线、复述和反馈。现阶段不以积分、连胜或无限滚动制造时长，也不声称已让学生“学上瘾”。
