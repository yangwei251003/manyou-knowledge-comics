# 五科科学图示与有限动画核对

日期：2026-11-05。文件：`src/diagrams.js`。本轮只修改该图示模块；未修改页面、样式或课程脚本。

## 调用约定

`diagram(id, step, value, thumb = false, progress = 1)` 返回内联 SVG。

- `step`：0–5，与 `content/lessons.js` 六幕一一对应。
- `progress`：0–1，读者翻幕时由页面驱动一次有限过渡。1 为完整稳定画面；函数本身不启动计时器、不循环。
- `thumb = true`：强制使用稳定终态，不播放动画。
- `value`：使用导出的 `modelControls[id].initial` 初始化；滑块操作应保留当前 `step`，然后传 `progress=1` 即时比较。不要把导数第六幕强行传成 step=3。
- 科学过程为解释用参数插值，`progress` 不等于真实时间；没有宣称完整动力学、化学动力学或大气数值仿真。
- 无第三方图像、代码或模拟程序复用；图形为项目原创 SVG。

可供独立核对的纯函数：`derivativeState`、`energyState`、`equilibriumState`。

## 分科改进与边界

### 数学

第1幕比较 x=±1 的同高异斜率；第2幕固定 P(1,1)、Q(2,4)；第3幕让 Q 有限靠近 P，主图演示右侧趋近，旁栏明确两侧的差商；第4幕显示真正的切线 y=2x−1；第5幕连接 f′(x)=2x 与单调区间，并对照割线；第6幕切换到 P(−1,1)，真切线为 y=−2x−1。

第5、6幕滑块均改变 h。第6幕的切线斜率始终是 −2，割线斜率为 −2+h。缩放使用同一坐标映射，点与直线由公式计算；不采用生成插画中的近似刻度。

### 物理

前4幕位置沿同一固定正弦形轨道的 t=0→0.28→0.50→0.68 连续推进，不反复往返填时间。势能按高度计算，动能与累计耗散补足同一初始能量。step=3 开始引入滑动制动；其后转入机械能与内能的账本比较。第6幕单独复盘零势能终点的数值题。

初始耗散参数为0.36，所以50 J初始机械能对应末动能32 J、内能增加18 J；改变滑块后明确显示“参数对照”。图示小车按质点处理、忽略轮子转动，不把该过渡当作真实小车时间轨迹或滚动摩擦仿真。

### 化学

step=2 开始等温体积变化，默认 V=0.5；先只改变浓度，再在下一幕表示重新平衡。归一化模型选 Kc=1，初始 c(NO₂)=1.5、c(N₂O₄)=2.25；全过程保持 V(c(NO₂)+2c(N₂O₄))=6。等温压缩瞬间 Qc/Kc=V；重建平衡后 Qc/Kc=1。

第5幕用三个相同观察框比较压缩前、压缩瞬间和新平衡，避免“右移就一定比原先颜色浅”的误读。滑块还原到 V=1 时显示“未压缩、无净移动”，不继续声称右移。代表性分子保留 N/O 组成，但分子图的数量不按定量浓度比例编码；颜色深浅也不是实测吸光度。

### 生物

从旧图2n=2改为与脚本、题目一致的2n=4。长短区分两对染色体、橙蓝区分来源；复制后4条染色体/8个核DNA，减Ⅰ胞质分裂后每细胞2/4，减Ⅱ完成后每细胞2/2。

减Ⅰ的移动保留姐妹相连、分开同源；减Ⅱ把姐妹分别移入4个子细胞。过渡中展示轮廓交叠仅用于解释分离关系，计数标签明确指完成状态，不能作为胞质分裂中间形态的真实重现。未展开纺锤体、交叉互换、异常分离与卵子发生的不均等胞质分裂。第6幕另作精细胞与卵子发生的区别，避免4个等大功能卵子的错误画法。

### 地理

0–3幕固定白天，step=4固定夜间，step=5才按滑块切换日夜对照。页面应只在第6幕开放海陆风滑块。

完整白天环流为近地面海→陆、陆地上升、高空陆→海、海面下沉；夜间适合形成陆风时反向。箭头有限描线后停住，不循环。相对气压文字移到竖直箭头旁，避免覆盖。温度条、气压和气流均为晴朗弱背景风条件下的相对示意，不提供测量值或广东实时天气结论。
